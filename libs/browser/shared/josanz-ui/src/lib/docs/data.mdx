# Datos

Tablas, grids, timelines y visualizaciones para listados ERP, dashboards y flujos operativos.

## Componentes incluidos

| Componente | Uso principal |
|------------|---------------|
| Data Table | Tablas simples con sort y selección |
| Data Grid | Búsqueda, paginación, CSV, resize columnas |
| Accordion / Timeline | Historial y secciones colapsables |
| Tree View | Jerarquías con checkbox opcional |
| Kanban Board | Flujos por columnas |
| Chart | Gráficos CSS (bar/donut) |
| Stat Card | KPIs en dashboard |

## Patrones recomendados

1. **Listados ERP:** `Main List Layout` + `Adaptive List Rows` o `Data Grid` según complejidad.
2. **Loading:** usar `loading` + `loadingSkeleton` en Data Grid para skeleton animado.
3. **Server-side:** activar `serverSide`, `paginated`, `totalRows` y escuchar `pageChange`.
4. **Selección masiva:** `selectable` + `selectedIds` / `selectedIdsChange`.
