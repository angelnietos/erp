# Formularios

Controles de entrada, validación y composición con `josanz-form-field`. Todos los inputs reactivos implementan `ControlValueAccessor` vía `JosanzValueAccessorBase`.

## Componentes incluidos

| Componente | Story | CVA |
|------------|-------|-----|
| Input | `Josanz UI / Input` | — |

## Patrones recomendados

1. **Siempre envolver** controles en `josanz-form-field` con `label`, `required`, `error` e `hint`.
2. **Formularios reactivos:** ver `Forms / Reactive Example` — `FormGroup` + `formControlName`.
3. **Estados obligatorios en stories:** default, disabled, error, hint-only.
4. **Shape:** usar toolbar Shape o `@Input() shape` para probar `rounded`, `pill`, `square`.

## Checklist al añadir un control

- [ ] Story `Playground` con controls
- [ ] Story `States` (disabled, error)
- [ ] Story `Interactive` con `play()` si emite eventos
- [ ] Integración en Reactive Example si tiene CVA
- [ ] Smoke spec si implementa CVA
